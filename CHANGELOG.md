## [0.1.0] - 2026-10-13

### Added

- Connection to the KNX bus through a KNX IP interface or router: UDP tunnelling, TCP tunnelling, KNX IP Secure tunnelling (tunnel user and password) and routing, with automatic reconnection.
- Search for the KNX IP interfaces of the network, used when the address of the interface is left empty.
- Devices declared from the configuration with the group addresses of the ETS project, then added from the Discover tab: lights (on/off, brightness, RGB color, color temperature), switches, shutters and curtains (up/down, stop, position), sensors (temperature, humidity, illuminance, CO2, pressure, wind speed, power, energy meters, voltage, current, percentage, counter), binary sensors (motion, presence, window contact, smoke, leak, rain) and thermostats (setpoint and measured temperature).
- States read at startup and at a chosen interval, and published within the Gladys rate limit.
- Dashboard widget "KNX bus": connection, telegrams per minute and the last telegrams, with Read states and Reconnect buttons.
- Scene triggers: a KNX telegram is received on chosen group addresses, the KNX connection is lost, the KNX connection is restored.
- Scene actions: send a value on the bus, read a value from the bus, recall a KNX scene.
- Texts in English, French, German and Spanish.
